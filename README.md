# AI QA Evaluator

A lightweight AI quality assurance tool for evaluating chatbot responses using structured human review.

## Why I Built This

AI responses can sound confident and useful while still containing subtle factual, contextual, or reasoning errors.

Drawing from my experience in AI quality assurance, I wanted to build a tool that turns subjective chatbot reviews into structured data that can be analyzed and compared.

## Current Features

- Upload chatbot response datasets via CSV
- Review individual prompts and responses
- Score responses using multiple quality criteria
- Add reviewer notes
- Assign Pass, Needs Review, or Fail ratings
- Track completed evaluations
- Calculate average quality scores

## Built With

- Python
- Streamlit
- Pandas
